# MUJI风格与视觉

复核日期：2026-10-20（初评归档于2026-10-16）。范围：最新尺寸校准模型及用户已确认布局。所有模型距离均为概念模型计算，不代替现场复尺；图纸上/下/左/右不等于地理南北。

角色：风格评估员。最新用户MUJI要求优先于早期樱桃木博主参考。采用自然橡木家具、暖白大背景、米色棉麻、少量绿植与简单灯具。地面仍保持用户要求的暖棕层次，避免漂白或橙红过重。

| 层次 | 目标 | 不应出现 |
|---|---|---|
| 墙顶/柜体 | 暖白、柔和哑光、简洁收口 | 大面积木格栅、岩板背景墙、复杂吊顶 |
| 地面 | 低对比自然暖棕木纹，细缝，轻微材质变化 | 均匀塑料亮面、强重复纹理、纯白地板 |
| 家具 | 橡木主色，低矮且边缘自然 | 全屋红棕樱桃木与深色拼盘 |
| 织物 | 棉麻、可辨织纹、自然褶皱 | 无纹理圆角塑料块 |
| 门窗 | 保留白色细框八格不透明玻璃门、黑色细窗框 | 新增侧窗、玻璃门变透明、把已取消的书房—客厅玻璃重新画回来 |
| 陈设 | TV左侧较高阔叶树、少量器物 | 满屋同一种仙人掌、道具堵通道 |
| 写实表现 | 人眼高度、柔和日光、接触阴影与粗糙度变化 | 拉宽房间、凭空大落地窗、过曝掩盖采光 |

布局以电视后暖白实墙、无厨房移门的开放L形为准；黑细框只用于外窗等仍保留的开口。真实材质感通过全景表现；尺寸精确性仍由校准模型承载。每个节点需要检查玻璃门分格、窗位、家具相对关系以及相邻节点是否一致。AI效果图不冒充实际拍摄。

七节点已直接目视复核，MUJI材质方向可用；电视实墙及开放厨房在相关节点一致。V-001的风格预览范围完成，V-002接入完成但门格数、家具细部、跨节点楼景和局部投影仍有生成误差；不视为工程验收通过。详见14生成后复核及15运行记录。
