## 查看

用浏览器打开本目录的 [index.html](index.html)，可离线浏览。可按风格连看全屋，或选择一个空间同时比较四套搭配。点击图片看原图，左右键切换，支持单张保存。解压完整压缩包后请保持目录结构。

## 风格

| 目录 | 风格 | 本轮关注 |
| --- | --- | --- |
| `forest/` | 林中树屋 | 深樱桃木、苔绿亚麻、灰米矿物墙、旧铜与自然叶影。 |
| `japanese/` | 现代日式中古风 | 中深胡桃木、橄榄绿、少量陶土色、纸光、编织与手作陶器。 |
| `french/` | 轻法式复古原木风 | 蜂蜜橡木、象牙白、灰蓝与旧玫瑰、克制墙线、藤编与黄铜。 |
| `sunlit/` | 日光花园原木 | 浅木包边与白台面、细条纹、鲜叶绿、少量柔粉和窗边植物。 |

## 文件记录

- [prompts.json](prompts.json)：四套实际完整生成提示词；各风格目录也保留对应记录。
- [manifest.json](manifest.json)：36 张最终图片的尺寸、文件体积与 SHA256 校验。
- 各风格目录下的 `manifest.json`：逐图生成来源等过程记录。

这组图专门用于判断风格效果。局部家具、门窗、厨房台面及近景陈设可能随概念机位调整，不能据图量取施工尺寸。原有模型与全景图保留，项目全景页和模型页已新增「概念设计图」入口；网站图册位于 `public/concepts/index.html`，进入时保留当前风格与房间。
