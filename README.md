# 栖光 · MUJI 风全景之家

默认进入 MUJI 风写实全景导览：客厅、餐厅与阳台、主卧与衣帽区、书房、客房、厨房、卫生间，共七个 360° 观察点。点击空间导航或热点跳转，拖动、触摸或方向键环顾，支持缩放、自动旋转、户型定位和截图。

全景由当前尺寸模型的等距柱状参考图经内置 imagegen 生成，属于 AI 设计效果，并非现场拍摄；局部细节与尺寸可能与模型有偏差。实际布局核对请进入 `?view=model` 保留的 Three.js 尺寸模型。所有最终图片位于 `public/panoramas/`，运行时不调用生图 API。

## 启动

需要 Node.js 22.12+。

```bash
npm install
npm run dev
```

打开终端提示的网址，默认 http://localhost:5173 。

```bash
npm run build       # TypeScript 检查与生产打包
npm run preview     # 预览 dist，默认端口 4173
npm test            # 导航与碰撞回归测试
npm run test:e2e    # 浏览器交互、模型连通性与移动端检查，先启动 dev
```

浏览器检查默认使用 `/usr/bin/google-chrome`，可通过 `CHROME_PATH` 指定可执行文件，通过 `BASE_URL` 更改测试地址。需要支持 WebGL 2 的浏览器。`dist` 可直接部署至静态网页服务器。

## 在线网站

网站地址：[https://telfyc.github.io/MyHome/](https://telfyc.github.io/MyHome/)。推送到 `main` 后，GitHub Actions 会自动安装依赖、运行单元测试、构建并发布到 GitHub Pages。也可以在仓库的 Actions 页面手动运行 `Deploy to GitHub Pages`。

部署构建使用 `VITE_BASE_PATH=/MyHome/`，以适配 GitHub Pages 的仓库子路径；本地开发和普通构建仍使用根路径 `/`。

检查子路径构建时，预览服务也使用相同配置：`VITE_BASE_PATH=/MyHome/ npm run preview`，访问提示的 `/MyHome/` 地址。

## 操作

默认全景模式的七个观察点覆盖九个功能区，玄关随公共区查看，阳台随餐厅查看。底部缩略图、左侧空间列表及户型图均可跳转。全景跳转标记是导览入口，不代表实体门洞。全景只有本次生成的日间效果，没有伪造夜间光照模拟。

以下为 `?view=model` 中的尺寸模型操作：

- 全屋鸟瞰：左键拖动旋转，滚轮缩放，右键平移；触屏单指旋转，双指缩放/平移。
- 室内漫游：WASD / 方向键移动，拖动环顾，Shift 加速，Esc 退出；屏幕方向按钮支持触屏。
- 点击左侧房间、3D 房间标签或小户型图切换空间；「走进这里」进入当前房间。
- 切换日夜、1.35 m 墙体剖切、空间标签。
- 相机按钮保存当前三维画面 PNG；「设计依据」可对照布局图、灯光图、原户型及日夜效果参考。

## 设计依据与估算

尺寸以 `docs/newStructure.jpg` 的手写标注为准，餐厅与上方阳台合计进深 3.45 m 已由用户确认；不复制新图中的旧墙、旧卫浴和窗符号。布局依据为 `docs/方案B/采光优化方案B.md`、B-1 / B-2 及后续确认；电视和木质电视柜继续沿用。详细尺寸、来源范围与估算项见 `docs/尺寸校准说明.md`。最新风格按用户 2026-10-16 的 MUJI 要求，采用暖白、自然橡木、暖棕地面与本色棉麻。`docs/山月知心的家_装修总体风格指导.md` 和三张旧效果图保留为早期参考。PDF 图纸与 B-1/B-2 内容一致；解压资料保留在 `docs/方案B`。

模型落实：

- 主卧与左上客房左侧的两处侧窗已取消，改为暖白实墙；各自下端 / 上端的原有外窗保留。
- 书房与客厅共享墙中段原景窗已补为完整暖白实墙，两端原实体段保留，取消玻璃、窗框和隐私帘，仍由原上方房门进出。
- 根据后续调整，电视改为约 65 英寸，配 1.80 × 0.42 × 0.47 m 木质矮柜，移至左侧墙面中段，正对右侧沙发。电视放在柜上，背后为完整暖白实体墙。
- 地面采用暖棕木色柔光木纹砖效果，暖白墙顶与大柜体构成连续背景；200 × 1200 mm 错缝纹理是本模型的概念规格，并非博主家的已核实参数。
- 门采用白色细框、一根中竖框和三根横框，分隔为两列四行的八块不透明磨砂玻璃；外窗使用黑色窗框。
- 电视左侧（坐在沙发面向电视时）增加约 1.7 m 高的阔叶落地植物；其余盆栽改为阔叶、舒展叶片与垂叶的不同造型。
- 电视柜、餐桌椅、床架和边几统一为自然橡木色，书桌与洗衣台面使用较浅的白橡木色；米色织物、少量茶具和植物补充生活感。
- 白天使用温和自然光，夜间区分基础光、书桌与厨房工作光、床边等局部氛围光，避免以强黄灯代替材质暖色。渲染色卡不是实测漆号或品牌采购参数。
- 书房高柜在上侧，1.70 × 0.58 m 双人桌在下方原外窗附近，左侧为临时客床。
- 左上独立客房/未来儿童房，中部独立卫生间，左下主卧入口改衣帽区。
- 餐厅 1.20 × 0.70 m 餐桌、左侧长凳、右侧两椅；右上开放式 L 形厨房、餐厅上方家政阳台。厨房朝餐厅和玄关的两面内隔墙、滑门、轨道和门套取消；原外墙、外窗和右下外轮廓墙段保留，不加岛台占用通道。
- 客厅下端保留不规则收窄轮廓；家具和墙体有行走碰撞，不能穿过电视背后的实体墙；开放厨房的两个方向均可通行。

## 代码位置

- `src/dimensions.ts`：新图净尺寸、统一墙体坐标与家具平移规则。
- `src/plan.ts`：房间关系、坐标、资料说明、房间视点。
- `src/model.ts`：墙体、门窗、家具、纹理、灯光、碰撞范围。
- `src/floor.ts`：独立的暖棕木纹砖纹理、概念铺装尺寸与柔光材质。
- `src/style-palette.ts`：依据风格指导与后续调整整理的MUJI 暖白、暖棕木、自然橡木、棉麻、门窗与灯光色卡。
- `src/viewer.ts`：Three.js 渲染、房间切换、漫游、日夜与截图。
- `src/navigation.mjs`：可独立验证的碰撞与移动逻辑。
- `src/main.ts` / `src/style.css`：中文界面与响应式样式。
- `public/references`：原始资料的浏览器可见副本。

尺寸模型使用真实三维几何，负责布局与通行核对；默认全景使用球面纹理，负责装修材质与氛围体验。两种模式的用途不同，不能从生成的全景反向量取施工尺寸。

## 整改复核

按 `docs/deepseek_markdown_20261015_dcefff.md` 收集资料、下载并检查评估技能、分角色复核。输入与来源清单、技能下载日志、按角色整理的专项、汇总与生成后复核报告位于 `home-design-review/`。网站提供 `public/review/summary.md` 复核摘要。未取得的朝向、现场洞口、结构、管线和预算数据在报告中标为待确认，不因图像质量改善而判定合规。
