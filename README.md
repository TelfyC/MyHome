# 栖光 · 轻原木之家

根据项目 `docs` 中的《采光优化方案 B》、B-1 / B-2 图纸和原始户型建立的可探索 3D 装修空间。使用 Three.js + TypeScript + Vite，全部房屋、家具、材质纹理由本地代码建立，无远程模型、图片或字体运行时依赖。

## 启动

需要 Node.js 22.12+。

```bash
npm install
npm run dev
```

打开终端提示的网址，默认 http://localhost:5173 。

```bash
npm run build       # TypeScript 检查与生产打包
npm run preview     # 预览 dist，默认端口 4173
npm test            # 导航与碰撞回归测试
npm run test:e2e    # 浏览器交互、模型连通性与移动端检查，先启动 dev
```

浏览器检查默认使用 `/usr/bin/google-chrome`，可通过 `CHROME_PATH` 指定可执行文件，通过 `BASE_URL` 更改测试地址。需要支持 WebGL 2 的浏览器。`dist` 可直接部署至静态网页服务器。

## 在线网站

网站地址：[https://telfyc.github.io/MyHome/](https://telfyc.github.io/MyHome/)。推送到 `main` 后，GitHub Actions 会自动安装依赖、运行单元测试、构建并发布到 GitHub Pages。也可以在仓库的 Actions 页面手动运行 `Deploy to GitHub Pages`。

部署构建使用 `VITE_BASE_PATH=/MyHome/`，以适配 GitHub Pages 的仓库子路径；本地开发和普通构建仍使用根路径 `/`。

## 操作

- 全屋鸟瞰：左键拖动旋转，滚轮缩放，右键平移；触屏单指旋转，双指缩放/平移。
- 室内漫游：WASD / 方向键移动，拖动环顾，Shift 加速，Esc 退出；屏幕方向按钮支持触屏。
- 点击左侧房间、3D 房间标签或小户型图切换空间；「走进这里」进入当前房间。
- 切换日夜、1.35 m 墙体剖切、空间标签、书房隐私帘。
- 相机按钮保存当前三维画面 PNG；「设计依据」可对照布局图、灯光图、原户型及日夜效果参考。

## 设计依据与估算

优先级：`docs/方案B/采光优化方案B.md` 与 B-1 家具图 > 原始户型轮廓 > 三张效果图的风格。PDF 图纸与 B-1/B-2 内容一致；解压资料保留在 `docs/方案B`。

模型落实：

- 书房与客厅共享墙两端保留实体承重段，只有中段是固定清玻璃，原上方房门进出。
- 根据后续调整，电视改为约 65 英寸，配 1.80 × 0.42 × 0.47 m 木质矮柜，移至左侧墙面中段，正对右侧沙发。电视放在柜上，屏幕和柜体会遮挡部分原玻璃景窗，借光面积相应减少；不在玻璃上安装支架。
- 地板改为独立的低饱和哑光浅橡木材质，200 × 1200 mm 错缝铺装、低对比木纹，与家具饰面分开设置。
- 书房高柜在上侧，1.70 × 0.58 m 双人桌在下方原外窗附近，左侧为临时客床。
- 左上独立客房/未来儿童房，中部独立卫生间，左下主卧入口改衣帽区。
- 餐厅 1.20 × 0.70 m 餐桌、左侧长凳、右侧两椅；右上封闭 L 形厨房、餐厅上方家政阳台。
- 客厅下端保留不规则收窄轮廓；家具和墙体有行走碰撞，不能穿过固定玻璃。

原资料明确为分区比例概念示意，并非统一比例施工图。因此模型按给定房间净宽与房间关系重建，其余位置、开口和家具为估算，不应反向用于施工。

| 项目 | 本模型 |
| --- | --- |
| 主卧 / 书房 / 客厅 / 餐厅参考净宽 | 约 3.25 / 2.75 / 3.30 / 2.50 m |
| 层高 | 暂取 2.70 m，待复测 |
| 中段玻璃 | 长约 1.47 m；窗台 0.42 m、上沿 2.36 m，均为高度意向 |
| 门、外窗比例与外窗标高 | 依据原图和住宅尺度估算，待复测 |
| 方位 | 保持图纸上下左右，不认定为地理南北 |
| 日夜模式 | 材质与人工照明氛围示意，非日照、照度或采光改善模拟 |
| 家政、中央卫浴 | 水电、排污与通风条件待核实 |

## 代码位置

- `src/plan.ts`：房间关系、坐标、资料说明、房间视点。
- `src/model.ts`：墙体、门窗、家具、纹理、灯光、碰撞范围。
- `src/floor.ts`：独立的浅橡木地板纹理、物理铺装尺寸与哑光材质。
- `src/viewer.ts`：Three.js 渲染、房间切换、漫游、日夜与截图。
- `src/navigation.mjs`：可独立验证的碰撞与移动逻辑。
- `src/main.ts` / `src/style.css`：中文界面与响应式样式。
- `public/references`：原始资料的浏览器可见副本。

模型是可旋转、可进入的实际三维几何，不是对效果图的全景模拟。家具采用程序化造型，视觉精细度与原效果参考图不同。
