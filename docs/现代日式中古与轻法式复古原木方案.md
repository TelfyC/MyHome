# 新增两套全景风格

两套方案沿用现有户型、开口、家具功能位和七个全景机位。图片是 AI 概念效果，不能据此量取施工尺寸；布局与通行仍以尺寸模型和现场复测为准。

| 设计要素 | 现代日式中古风 | 轻法式复古原木风 |
| --- | --- | --- |
| 背景 | 暖白哑光墙面、中性暖棕地面 | 象牙白墙面、浅蜂蜜木地面、细线条装饰 |
| 家具 | 中深胡桃木、柚木色、低矮轮廓与锥形腿 | 浅蜂蜜橡木、轻柔曲线、少量藤编与细黄铜 |
| 织物 | 原色亚麻、橄榄绿、陶土色、几何地毯 | 奶油白亚麻、灰蓝、旧玫瑰、轻复古花纹 |
| 灯光 | 纸罩灯、陶器、局部暖光 | 布罩灯、细黄铜灯具、柔和局部光 |
| 植物 | 靠实际窗位的一株轻盈观叶或枝条，少量香草 | 窗边观叶、疏朗瓶花与厨房香草 |

## 各空间重点

- 客厅：日式中古以胡桃木矮柜、纸灯与几何地毯组成低重心；轻法式以浅木柜、复古地毯、灰蓝靠垫与小幅画作增加层次。
- 餐厅：分别使用胡桃木餐桌与编织椅、浅蜂蜜木弧线餐桌与藤编椅；咖啡柜沿用原有位置和功能。
- 主卧与客房：保持低床、收纳和通道，日式用胡桃木与橄榄绿，法式用浅木、奶油白、旧玫瑰和灰蓝。
- 书房：日式用柚木写字桌与手作陶器；法式用浅木桌、细黄铜灯与植物画；工作台面保持可用。
- 厨房：保留冰箱、洗切炒台面和开放餐厨关系。日式以胡桃木色下柜配暖白上柜，法式用象牙白柜体、浅木与细黄铜。
- 卫浴：两套均保留洗衣机与台盆共台、马桶和淋浴位。木色仅表达防潮柜门效果，湿区真实材料需按现场条件选用。

## 图片生成要求

使用内置 imagegen，逐张以奶白原木方案的对应全景作为编辑目标。每张提示均要求保留 2:1 等距柱状投影、机位、现有窗门与墙体、主要家具功能位、厨房和卫浴设备以及可通行路线。日式中古的房间提示分别加入胡桃木矮柜与纸灯、胡桃木餐桌与陶器、低床与橄榄绿、柚木书桌、简洁客床、暖白加胡桃木厨房、防潮胡桃木色卫浴柜门。轻法式房间提示分别加入浅木柜与复古地毯、弧线餐桌与花、浅木床与轻织物、写字桌与细黄铜灯、柔和客床、象牙白厨房、防潮浅木色卫浴柜门。统一限制：适量植物、自然日光加局部柔光，无人物、可读文字、水印或新增结构。
