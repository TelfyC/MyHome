# 第二版采光方案 B｜中段景窗玻璃书房

2026-10-15｜沿用已确认的中部卫生间方案｜两人居住，未来左上房间转儿童房

## 结论

保留书房与客厅之间两端的承重墙，只在中间可拆的白色墙段设置透明玻璃。书房下方已有外窗，利用该窗与中段玻璃形成借光关系；同时清空玻璃两侧，沙发与电视位置对调。

这是在现有承重约束下的一版概念方案，现有信息足以讨论布局。它不承诺形成整墙外窗、无遮挡窗景，也没有通过日照或照度模拟证明改善幅度。

## 2. 玻璃怎么做

优先采用固定透明玻璃，保留书房上方原房门作为进出通道。这个玻璃不必再兼任移门，避免为了通行增加框扇和五金；如果后续希望客厅直接进入书房，再在实测范围内比较可开启形式。

玻璃两端承重墙保留，收边保持窄而简洁，颜色以暖白或浅木色小范围点缀。它的视觉定位是“嵌在实体墙里的景窗”，不是把两段承重墙包黑后假装整墙落地玻璃。

书房侧预留可完全收拢的遮光/隐私帘。日常收起，留宿时拉上；帘子打开后的堆叠区尽量不占玻璃净透光面。整面磨砂或长期开着的百叶会削弱通透感，本版优先清玻璃加可收帘。

若拆除范围只允许保留窗台，上下仍有实体墙，就做对应高度的室内玻璃窗；若确认整段可拆至地面且梁底边界明确，再做接近落地的玻璃。两种都只在原白色段内实现。

玻璃厚度、支承、边框、碰撞安全、隔声和密封由实际洞口尺寸与产品体系确定，不在概念图里指定一个未经校核的厚度。未来有宝宝时，应兼顾玻璃可识别性和抗碰撞设计。窗与玻璃本身不等于新增通风量，书房仍利用原外窗通风。

## 3. 书房：让光走得出来

上一版右侧高柜会挡住借光界面，本版取消该位置的高柜。

- 衣柜移到上方左侧短墙，深约550mm、长约1200-1400mm候选，避开右上原门扇。
- 双人书桌移到下方原窗附近，初选长1600-1800mm、深550-600mm；桌面高度、窗扇开启和窗帘需一起核对。桌上不设置高书架或通顶背板。
- 临时客床留在左侧，用可收折形式；图上表达展开睡眠面意向，展开后可能需收起工作椅，不作为长期第三人卧室。
- 中段玻璃前不设高柜、长满书的展示架或固定床头；电脑屏幕与桌面物品也应尽量不形成连续遮挡。

纸面约2750mm净宽是现有估算，柜门开启、桌椅使用与客床展开必须按产品外径复核。

## 4. 客厅：沙发和电视对调

沙发从左侧移到右侧实体墙前，面向左侧，候选长2000-2100mm、深850-950mm。下端收窄区保持通道和低矮、可移动家具。

电视移到左上承重短墙段前，优先用可转向的落地电视架，避免把电视挂在中段玻璃上，也避免靠加柜体封堵玻璃。屏幕朝沙发主坐位微调；图纸上电视与沙发存在一定纵向错位，因此本版采用可转向方案，而非假装已经形成完美正对的电视墙。

这段短墙的实际长度决定屏幕大小。先量可用长度和主坐位，再定电视，不预设必须65/75英寸。若用户需要大电视，而此短墙与转向使用无法满足，应改用可移动大屏或重新比较客厅排法，不能覆盖玻璃借光区凑电视墙。

电视架用电与网络预留同步移到左上。屏幕不承担隔断作用，设备线缆可检修。若最终改壁挂，安装条件需单独确认；概念设计不等于允许在结构墙上任意剔槽或破坏钢筋。

中段玻璃面对的客厅中央留作通行、活动和未来宝宝地垫区，不设大茶几。借来的光先进入这片空地，再参与室内漫反射。

## 5. 其他空间保持的关系

- 左上：现在客房，未来儿童房，保持独立、完整的实体房间。
- 中上狭长区：已调整的独立卫生间，位置与门朝下方公共过道的安排保留。
- 左下：主卧和上方入口衣帽区；不恢复旧候选卫浴。
- 餐厅：1200×700mm桌、左侧长凳、右侧活动椅，保证主通道。
- 厨房：保留封闭L形厨房意向。
- 餐厅上方阳台：家政候选与植物少量布置，水电排污条件仍需核实。

## 6. 光与材质

维持主 Skill 的简单背景与家具定义风格原则：暖白墙顶和大柜、浅木纹地面、米白织物、少量温和木家具。玻璃附近的侧墙和顶面尽量浅色，不增加深木色包墙。书房外窗与客厅下端开口附近不设高遮挡，厚帘拉开后尽量收在玻璃面外。

B-2 的绿色箭头只画出“书房外窗—书房中部—共享墙玻璃—客厅活动区”的借光意向，不是光线追踪，也不意味着转折处会有一束定向阳光。阴天、朝向不利或楼外遮挡较重时，客厅深处仍可能需要补光。

客厅保留独立可调基础光，可用柔和照墙方式减轻深处的昏暗感；不以满屋暖黄灯或高曝光渲染代替采光。电脑桌仍需任务照明。

## 7. 下一轮只需补的关键数据

概念方案不必等待这些数据才讨论，但深化前需量：
1. 可拆白色段沿墙的净长度，以及其两端到房间角的距离。
2. 可拆范围的下边界和上边界：能否到地面、梁底距地高度、有无不可拆窗台。
3. 书房下方窗洞的宽、高与窗台高；客厅下端现有开口的实际情况。
4. 你希望的电视尺寸，以及是否接受主坐位略微转向观看。

拿到前两项，才能确定景窗比例与玻璃形式；拿到后两项，再确定电视与沙发的最终位置。不需要为做这版方案重新决定儿童房或卫生间位置。
