# 日光花园结构校正工作流 · 2026-11-02

本轮按最新风格图调整空间关系和家具摆位，同时保留旧版。可查看的完整工作流位于[网页资料目录](../public/concepts/spatial/sunlit/workflow.md)，结构约束位于[constraints.json](../public/concepts/spatial/sunlit/constraints.json)。

关键处理是把手写尺寸、后续用户确认与当前墙线合成一个事实源：不直接复用旧Plan C，不把导航矩形当建筑轮廓，不用效果图推导窗或尺寸。全屋20个外转角顶点、主卧入口内凹、9处窗、5处门，以及最新厨房L台/收门和客厅阅读位单独锁定。

运行`python3 scripts/check-sunlit-spatial.py`检查实际导出的场景、家具轮廓和相机。几何报告与AI图片目视复核分离；前者通过不能证明后者准确。每张效果图需和同机位结构底图核对，结构错误应修正或清楚标注，不能宣称所有照片获得精确几何保证。

原始照片存在透视、缺少完整测量，墙厚/层高/门窗宽高和部分偏移均保留模型假设身份。这里的统一性是项目内部可核验的一致性，不能冒充施工级实测精度。
