# 林中树屋｜第二套材质与植物方案

> 2026-10-21 更新：本方案中的原书房统一改为电竞房，桌子靠主卧共墙，加入洞洞板与玻璃展示柜，取消临时客床；当前布局与走线见 [电竞房布局与走线](电竞房布局与走线.md)。下文原书房描述仅作历史参考。

这套方案沿用现有户型和功能布局，把“树屋”理解为室内的木纹、叶影和安静感，不额外改变墙体、开窗或通行空间。全景图是概念效果，家具、门窗细节仍以尺寸模型和现场复测为准。

## 材质层次

- 背景：奶油白矿物感墙面搭配局部自然木饰面，保留房间的明亮感。地面用连续的中性自然棕木纹统一公共区。
- 主家具：深色樱桃木用在客厅电视柜、餐桌与咖啡柜、主卧低床、书房小柜、卫浴柜门。采用哑光细纹，避免整屋大面积深木色压暗空间。
- 软装：本色亚麻、燕麦色织物和少量苔绿色。纹理以棉麻、藤编和木纹为主，减少高亮金属与强烈图案。
- 卫浴：深樱桃木色仅用于防潮柜门的视觉方案；真实选材需按湿区条件确认，不把实木直接用于易受水浸位置。

## 植物配置

| 空间 | 植物与摆放 | 控制点 |
| --- | --- | --- |
| 客厅 | 明亮窗边一株中型榕树，旁边配一盆蕨类 | 与窗、电视柜及通路保持距离；深处不堆绿植 |
| 餐厅与咖啡角 | 咖啡树或同体量观叶植物靠窗，层板上一盆垂叶绿萝 | 叶片不接触餐食与咖啡器具 |
| 主卧 | 窗边一盆小型蕨类，层板少量垂叶 | 不占床侧活动范围 |
| 书房 | 窗边蕨类，书架一盆绿萝 | 不遮挡桌面自然光 |
| 客房 | 窗边一盆蕨类 | 留出家具调整和行走空间 |
| 厨房 | 窗边少量香草，远离灶台的高层板上一盆绿萝 | 远离热源、油烟和备餐台面 |
| 卫浴 | 有自然或稳定补光时放一盆耐湿蕨类 | 无合适光照时使用切枝或不摆活植物 |

植物品种和具体位置最终按窗边实测光照、通风与养护条件调整。图中叶影是氛围表达，不能据此判断真实日照方向。
