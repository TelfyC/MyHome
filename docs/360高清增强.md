# 360° 全景 AI 超分增强

现有写实全景保持为设计依据，没有使用尺寸模型重新出图。原始 `public/panoramas/` 图片保持不变，增强文件独立存放在 `public/panoramas-hd/`。

## 输出与限制

- 输入：1774 × 887。
- 桌面增强：7096 × 3548，长宽各为原图 4 倍。
- 手机增强：3548 × 1774，从增强结果降采样，减少下载量与显存占用。
- 方法：Real-ESRGAN general-wdn-x4v3 弱降噪模型，本机 ONNX Runtime 推理。最终混合 85% 增强结果与 15% 原图 Lanczos 插值，控制过度平滑。

这是 AI 推断细节的超分处理，不是原生 8K 渲染，也不是对真实施工细节的精确复原。源图中已有的几何、门窗与球面投影偏差仍然存在。

## 浏览与对照

默认先加载原图，让房间尽早可看，再后台加载增强文件。增强成功时只替换纹理，保留用户正在看的朝向、俯仰、缩放与自动旋转状态。小标记显示增强加载进度及“AI 增强”。

手机视口或最大纹理尺寸不足 7096 的设备使用 2 倍版本；连 3548 都不支持的设备保留原图。增强文件加载失败时也保留可交互的原图。

同一房间可用以下链接比较，视角设置保持一致：

- 增强：`?design=forest&room=living`
- 原图：`?design=forest&room=living&quality=original`

## 分块与接缝

推理核心块为 256 × 256，每边额外取 40 像素上下文。模型是有限感受野卷积网络，40 像素超过其 34 像素半径；推理后裁掉上下文，仅拼接核心区域。经度方向循环取样、纬度边界反射，避免处理过程新增块间边线。此方法不会修复原图本身已有的左右内容错位。

真实图片探针的单块／分块一致性报告保存在本地 `artifacts/panorama-superres-20261027/`。输入输出维度、原图和模型哈希、增强强度及网页文件校验值记录在 `home-design-review/input/panorama-superresolution-20261027.json`。

## 重建命令

需要 Python、NumPy、Pillow、ONNX Runtime；生成过程在本机运行，不向外部服务上传图片。

```bash
# 生成单间无损母版，默认保留完整模型结果。
python3 scripts/upscale-panoramas.py \
  --model /tmp/home3D-superres-model/realesr-general-wdn-x4v3.onnx \
  --source public/panoramas/forest/living.jpg \
  --output artifacts/panorama-superres-20261027/forest/living-wdn-4x-master.png

# 生成四套风格；复用哈希匹配的已有母版，并输出平衡强度的网页版本。
python3 scripts/build-panorama-hd.py \
  --model /tmp/home3D-superres-model/realesr-general-wdn-x4v3.onnx \
  --workers 2 --threads 4 --strength 0.85

npm run build
npm run test:quality
```

单间脚本拒绝覆盖已有文件；批处理只会更新独立的增强目录，始终保留原图。网页 JPEG 采用 quality 94、无色度抽样及渐进编码。
