# 四套风格：设计师方法、细节与生活陈设

2026-10-26，第二轮。用户补充：设计细节和画面质感都要优化，尤其是物品摆放显得随意、缺少生活化的小装饰。

## 这轮重新检查了什么

上一轮只把全景中的柜体、织物等要求细化，仍存在两个实际问题：四套方案大量沿用相似家具和陈列；每张 1774 × 887 的图铺满整个 360°，正常视角只是其中一小部分，近看材质会糊。试验要求更高尺寸后，内置生图仍返回相同的全景尺寸。

因此这轮保留已有 360° 作为空间关系参考，另为四套风格的七个房间各制作一张独立、正常透视的空间效果。新图原生 1536 × 1024，整张图用于当前视角，未把低像素全景机械放大。默认进入新空间效果，可随时切到“360° 环顾”；两种图片的局部软装、材质和陈列可能不同，尺寸与门片占位仍以模型为准。

只学习公开作品中可迁移的方法，不把设计师项目直接套入本户型，也不把项目照片当成本家的效果。

这是本项目基于公开作品的学习与转化，四位设计师没有参与本项目。

## “生活化”如何变成有逻辑的摆放

共同规则是先确定活动，再安排物件。常用物放在伸手可及处；同一活动的小物在同一托盘、层板或墙面里；用颜色、材质与高低关系组织，给工作和通行留空。

| 空间 | 成组的小物与装饰 | 保留的使用空间 |
| --- | --- | --- |
| 客厅 | 阅读边几：台灯、打开的读物、杯垫与杯；茶几：低托盘与少量叠书；电视柜端：小相框、手作小器物 | 至少半张茶几空着；窗边植物成组，客餐主路不放零散花盆 |
| 餐厅／咖啡 | 机器和磨豆机在同一托盘，杯具就近集中；餐桌用桌旗、低果盘和常用杯 | 咖啡机可开盖、插座可用，餐桌保留吃饭的位置 |
| 主卧 | 床边托盘集中读物、杯子与充电物；另一侧独立灯与小相框；薄毯、靠垫柔和搭配 | 不堆满床头，衣帽通路不摆大凳或花盆 |
| 电竞房 | 耳机、手柄挂放；桌垫和杯垫定位；不同收藏、书与卡片疏密陈列 | 键鼠区与椅后保持空，线缆沿墙和桌下收纳 |
| 次卧 | 桌端工作组、少量卡片和分组书；绿色床品、细条纹靠垫、薄毯与读物 | 左床右长桌关系保留，窗台和电脑旁留可用位置 |
| 厨房 | 砧板、常用工具、调味托盘靠近备餐；清洁用品在水槽边集中，窗边少量香草 | 连续备餐段、移门收拢区、冰箱与通行位置不被装饰占用 |
| 卫浴 | 皂液与牙刷杯的小托盘、顺手毛巾、闭柜收纳、湿区外低衣篮 | 台盆和洗衣操作面留空，淋浴瓶罐集中，避免杂物散落 |

## 四套风格分别改了哪些细节

- **林中树屋**：重点木作采用安静的直纹和内退底座，地毯、阅读灯与抽屉细节更克制；后续根据用户补充，单独修正七张图中的生活陈设，加入书、杯具、相框、笔记和顺手收纳，保留原有绿色氛围。
- **日式中古**：收紧木件和小五金比例，纸灯与阅读／工作光分开；收藏不再是一排相同玩偶，书、杯、卡片与器物形成疏密关系。
- **轻法式**：控制线条与家具曲度，淡化过于重复的复古符号；浅木、旧黄铜、柔和织物与日常器物协调，保留读写、咖啡与床边的活动位置。
- **日光花园**：保留浅木边白茶几、细条纹和窗边植物；补齐桌端阅读组、杯具组、咖啡陈列和小型相框，控制植物与器物的落点。

所有新图都以当前房屋的全景作为布局参考，保留已确认的次卧一人左床右桌、电竞桌沿主卧共墙、原电视墙，以及厨房扩容和顶部叠收玻璃门。生成图对餐椅方向、局部窗比例、柜体尺寸和玻璃分扇仍可能有偏差；不从效果图推导施工尺寸。

## 页面和模型

默认“空间效果”使用独立新图，支持放大、拖动、复位和保存；“360° 环顾”保留原环顾交互，两者切换保留房间和风格。新默认视图不依赖 WebGL。“摆放与装修细节”显示当前空间的三组生活摆放、材料、布局与收口说明，并提供对应设计师的来源链接。

尺寸模型保持现有布局，另外把织物的凹凸尺度从过强的 12 mm 调整到约 0.8 mm 的渲染值，为木材添加约 0.45 mm 的细微凹凸，以减少不合尺度的表面感。这些是概念渲染参数，非采购规格。

## 素材与提示词

- 最终新图：`public/room-views/{forest,japanese,french,sunlit}/{room}.jpg`。
- 新缩略图：同目录 `{room}-thumb.jpg`。共 28 张空间图和 28 张缩略图。
- 原 360° 参考：`public/panoramas/{style}/{room}.jpg`，本轮没有把旧图改称高分辨率全景。
- 公共设计与布局约束：`home-design-review/logs/craft-refinement-20261026/spec.json`。
- 用户补充的生活陈设要求：同目录 `daily-styling.json`。
- 每张图的实际提示词与源路径：同目录 `{style}-{room}.json`；林中树屋采用后续 `{style}-{room}-styling.json`。
- 安装脚本：`home-design-review/logs/install-craft-refinements-20261026.py`。
- 最终尺寸、体积、SHA256 与记录路径：`home-design-review/input/craft-refinement-manifest-20261026.json`。

使用内置 image_gen 生成和编辑；未使用 CLI／API。图片按原生尺寸写入项目，没有通过插值放大宣称生成更多细节。
