# 日光花园 · 风格整体优化

2026-11-02

本轮根据“浅木色过于统一，借用树屋的深木餐桌增加层次”的讨论，完成日光花园七个空间及两张细节近景的整体优化，并增加咖啡柜暖白移动插排。

## 看图入口

- 项目选择日光花园后，顶部「日光花园优化图」直接进入当前空间。
- 四风格概念图册默认显示日光花园优化版，可切回初版。
- Plan C 页面也有「日光花园 · 整体风格优化」入口。
- 独立页面：`public/concepts/sunlit-refined.html`，支持空间筛选、版本对照、放大及保存。

## 配色与材质

暖白和浅蜂蜜木为大面积基础。深栗樱桃木约 `#6b4435` 为视觉参考，用在餐桌、边几、托盘、主卧床组及次卧床头柜；电竞房仅用腕托等小件呼应。地板、椅凳和大面积柜体维持较浅明度。织物控制在米白细条纹、鼠尾草绿和少量灰粉，陶器统一米白与柔绿。

厨房上柜改暖白，下柜保留浅木；卫生间仅用深棕耐水陶托盘呼应。开放层板与台面陈设减量，绿植集中在有窗光的位置，并减少床头、设备上方的垂藤。

## 细节与记录

完整逐空间看图复核在 `public/concepts/optimized/sunlit/review.md`。修正了阅读椅和咖啡机在主图与近景间的不一致，并针对杯子把手、插排空孔及多余电线做局部重绘。

暖白短条移动插排位于磨豆机右侧干区后墙，可取下支架为设计意图。开关可及，后角理线；产品负载与设备连接方式按实选说明书核对。
