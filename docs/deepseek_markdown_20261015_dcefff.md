# 房屋装修设计方案 AI 评估与整改指令文档

> 版本：v1.0  
> 用途：已有 3D 效果方案图 / 平面布置图，需要对全屋细节进行专业评估，并输出可执行的整改意见。  
> 适用 AI：Claude Code、Cursor、Codex、Gemini CLI 等支持 Agent Skill、本地命令执行和文件读写的 AI 工具。  
> 核心目标：让 AI 按不同专业角色分工，逐步下载/调用评估 Skill，对整个屋子进行系统性评估，最终输出问题清单、评分表和整改优先级路线图。

---

## 0. 给项目 AI 的最高优先级指令

你是一个“装修设计多智能体评估系统”。请严格按本文档逐步执行：

1. 不得跳过资料收集、Skill 下载、自检和分角色评估步骤。
2. 所有评估必须基于用户输入资料、图纸尺寸和可验证标准，不得编造缺失尺寸。
3. 如果某项 Skill 下载失败，记录失败原因，并启用本文档第 9 节的降级方案继续评估。
4. 必须按不同专业角色分工评估，最后汇总为一份总报告。
5. 输出必须包含：问题描述、证据、严重程度、整改建议、具体尺寸/做法、参考标准、预计成本、优先级。
6. 最终输出保存到 `output/` 目录，并生成可读的 Markdown 报告。

## 1. 输入资料清单

请先收集并放入 `input/` 目录：

- [ ] 户型图 / 平面图（最好带尺寸标注）
- [ ] 各房间 3D 效果图 / 方案图
- [ ] 现有设计说明、材料清单、家具清单
- [ ] 房屋朝向、楼层、窗户位置、采光面
- [ ] 承重墙、管道、燃气、烟道、强弱电箱位置
- [ ] 居住需求：人数、年龄、生活习惯、收纳需求、宠物、烹饪频率
- [ ] 预算范围、可接受的改造程度
- [ ] 已知不可变项：不能拆的墙、不能移的管、必须保留的家具等

如果缺少关键尺寸，AI 必须列出“待确认问题”，不得自行假设。

## 3. Skill 下载与安装

### 3.1 必装 Skill

#### Skill A：Interior Space Layout Design Agent Skill

用途：全屋系统性评估，8 维度评分，输出改进路线图。

```bash
git clone https://github.com/dungnotnull/interior-space-layout-design-agent-skill.git skills/interior-space-layout
```

#### Skill B：Interior Design Expert

用途：动线评估、IES 照明标准、比例与尺度分析。

```bash
npx skills add https://github.com/erichowens/some_claude_skills --skill interior-design-expert
```

#### Skill C：blueprint-validate

用途：对照人体工学间隙、模块网格、采光朝向、层次分离等原则审查平面图。

```bash
npx skills add https://github.com/wjlgatech/design-anything --skill blueprint-validate
```

#### Skill D：Renovation Plan Diagnosis Assistant

用途：装修方案诊断，检查布局、功能分区、收纳、风格与硬装边界、安装风险。

安装方式：在 AI 聊天中按 skillhub.cn 的提示加载。

## 4. 角色分工

AI 需要模拟以下角色，依次评估，最后汇总。每个角色可以独立输出一份子报告。

### Agent 0：总协调

职责：
- 读取所有输入资料
- 建立房间清单
- 分配评估任务
- 汇总各角色报告
- 生成最终整改路线图

输出：`output/00-总报告.md`

### Agent 1：空间规划与人体工学评估员

使用 Skill：Interior Space Layout Design Agent Skill、blueprint-validate

检查项：
- 门宽是否 ≥800mm
- 走廊是否 ≥900mm
- 主要通道是否 ≥900–1200mm
- 次要通道是否 ≥600–900mm
- 家具间距、开门空间、抽屉拉出空间
- 房间比例、家具尺度是否匹配
- 是否存在卫生死角、空间压迫、伪需求

输出：`output/01-空间与人体工学.md`

### Agent 2：动线评估员

使用 Skill：Interior Design Expert、Renovation Plan Diagnosis Assistant

检查项：
- 入户到客厅、厨房、卧室、卫生间的主动线是否顺畅
- 是否穿越工作区、就餐区、休息区
- 高频路线是否被家具阻挡
- 家务动线、访客动线、居住动线是否交叉混乱
- 厨房、卫生间、阳台之间的家务路径是否合理

输出：`output/02-动线评估.md`

### Agent 3：采光与照明评估员

使用 Skill：blueprint-validate、DIALux evo（可选）

检查项：
- 每个可居住房间是否有朝向合理的窗户
- 窗地比是否合理
- 是否存在暗厅、暗卫、暗厨
- 是否只有单光源，缺少分层照明
- 环境光、任务光、重点光是否配置
- 是否存在眩光、阴影过重、色温混乱
- 太阳朝向和季节性光照是否被考虑

输出：`output/03-采光与照明.md`

### Agent 4：厨房专项评估员

使用 Skill：工作三角原则、Coohom AI Kitchen Workflow Layout、虾评 Skill 厨房布局优化助手

检查项：
- 冰箱、水槽、灶台三点工作三角
- 三角形每边 1.2–2.7m，总周长 4–8m
- 厨房主通道宽度
- 台面连续操作区
- 收纳容量与使用频率
- 烟道、燃气、排水、冰箱开门方向
- 多人烹饪是否冲突

输出：`output/04-厨房专项.md`

### Agent 5：收纳与功能评估员

检查项：
- 玄关、客厅、厨房、卧室、卫生间、阳台收纳是否足够
- 收纳分区是否合理
- 是否预留清洁工具、行李箱、换季衣物、宠物用品位置
- 插座、开关、网络、智能家居点位是否合理
- 是否存在“看起来好看但不好用”的设计

输出：`output/05-收纳与功能.md`

### Agent 6：风格与视觉协调评估员

检查项：
- 材质、色彩、灯光是否统一
- 硬装与软装边界是否清晰
- 是否过度装饰或风格冲突
- 视觉重心、比例、色彩温度是否协调
- 效果图与落地可行性是否一致

输出：`output/06-风格与视觉.md`

### Agent 7：构造、落地与规范评估员

检查项：
- 设计是否可施工
- 是否涉及承重墙、燃气、消防、防水等风险
- 水电点位是否可实施
- 是否使用标准件，避免专有件过多
- 是否符合当地基本规范
- 是否存在安装冲突、门扇碰撞、抽屉卡滞

输出：`output/07-构造与规范.md`

### Agent 8：预算与整改优先级评估员

检查项：
- 每个问题的整改成本：低 / 中 / 高
- 每个问题的影响：安全 / 功能 / 美观 / 预算
- 是否影响工期
- 是否影响后续不可逆工程
- 优先级：P0 必须改、P1 建议改、P2 可优化

输出：`output/08-优先级路线图.md`

### Agent 9：汇总整改员

职责：
- 合并所有子报告
- 去重、归类、排序
- 生成最终整改意见
- 输出总报告和问题清单

输出：`output/09-最终整改意见.md`

## 5. 逐步执行流程

### Step 0：初始化

- 读取 `input/` 所有资料
- 建立房间清单：玄关、客厅、餐厅、厨房、卧室、卫生间、阳台、走廊等
- 建立项目档案：面积、朝向、楼层、居住人数、预算、不可变项

### Step 1：安装 Skill 并自检

- 执行第 3 节安装命令
- 记录成功和失败项
- 启用降级方案

### Step 2：提取全屋基础信息

输出 `output/10-基础信息表.md`，包含：

| 房间 | 面积 | 朝向 | 窗户 | 门 | 主要功能 | 已知问题 |
|:---|:---|:---|:---|:---|:---|:---|
| 客厅 |  |  |  |  |  |  |
| 厨房 |  |  |  |  |  |  |

### Step 3：调用 Skill A 做全屋 8 维度评分

评分维度：
1. 空间规划
2. 人体工学
3. 动线流通
4. 采光
5. 照明
6. 收纳
7. 美学
8. 落地可行性

输出 `output/11-评分总表.md`：

| 维度 | 得分 | 证据 | 主要问题 | 改进方向 |
|:---|:---|:---|:---|:---|
| 空间规划 |  |  |  |  |
| 人体工学 |  |  |  |  |

### Step 4：动线与人体工学评估

- 调用 Skill B、Skill C
- 检查门宽、走廊、通道、家具间距
- 检查主动线、家务动线、访客动线
- 输出问题条目

### Step 5：采光评估

- 调用 Skill C 检查朝向和窗户
- 如有条件，用 DIALux evo 对客厅、卧室、厨房做定量模拟
- 输出采光问题与整改建议

### Step 6：厨房专项评估

- 计算工作三角
- 检查通道、台面、收纳、烟道、燃气
- 调用厨房 Skill 或清单
- 输出厨房专项报告

### Step 7：分房间评估

对每个房间依次评估：

- 玄关：换鞋、收纳、通行、落尘
- 客厅：沙发电视距离、动线、采光、插座
- 餐厅：餐桌尺度、通行、照明
- 厨房：工作三角、收纳、通风
- 卧室：床侧通道、衣柜开门、遮光、插座
- 卫生间：干湿分离、排水、通风、防水、门开向
- 阳台：晾晒、排水、承重、收纳
- 走廊：宽度、照明、收纳

### Step 8：汇总问题清单

将所有问题按房间和维度归类，生成 `output/12-问题清单.md`。

### Step 9：输出整改意见

每个问题必须包含：

```markdown
### 问题 ID：K-001
- 位置：厨房
- 问题：冰箱—水槽—灶台工作三角总周长超过 8m
- 证据：平面图标注尺寸为……
- 严重程度：高 / 中 / 低
- 涉及维度：厨房动线
- 整改建议：将水槽移至……
- 具体尺寸/做法：……
- 参考标准：工作三角总周长 4–8m
- 预计成本：低 / 中 / 高
- 优先级：P0 / P1 / P2
```

### Step 10：复核与迭代

- 检查整改建议是否互相冲突
- 检查是否影响结构、水电、燃气
- 检查预算是否可接受
- 生成最终版 `output/09-最终整改意见.md`

## 6. 通用检查清单

### 6.1 人体工学尺寸速查

- 门宽：≥800mm
- 主走廊：≥900mm
- 主通道：900–1200mm
- 次通道：600–900mm
- 厨房工作三角：每边 1.2–2.7m，总周长 4–8m
- 沙发与茶几：约 300–450mm
- 电视与沙发：约 2.5–3.5m，视尺寸而定
- 床侧通道：≥600mm
- 衣柜开门：≥600mm
- 餐桌通道：≥750mm

### 6.2 采光与照明

- 每个可居住房间应有合理朝向窗户
- 避免暗厅、暗卫、暗厨
- 使用分层照明：环境光 + 任务光 + 重点光
- 色温统一：公共区 3000–4000K，卧室 2700–3000K
- 避免单光源造成刺眼阴影

### 6.3 厨房

- 工作三角是否合理
- 冰箱开门是否受阻
- 灶台是否靠近烟道
- 水槽是否靠近排水
- 台面操作区是否连续
- 多人烹饪是否冲突

### 6.4 卫生间

- 干湿分离
- 排水坡度
- 通风换气
- 防水高度
- 插座防水
- 门开向是否合理

### 6.5 收纳

- 玄关：鞋、外套、包、钥匙
- 厨房：锅具、食材、小家电
- 卧室：衣物、被褥、行李箱
- 卫生间：洗漱、清洁、毛巾
- 阳台：晾晒、清洁工具

## 9. 降级方案

如果某些 Skill 无法下载或安装失败：

1. 使用本文档第 6 节检查清单进行人工规则评估。
2. 使用以下提示词让 AI 扮演对应专家：

```text
请以室内设计监理和人体工学专家的身份，评估以下平面图/效果图。
重点检查：门宽、走廊、通道、家具间距、动线交叉、采光朝向、厨房工作三角。
输出：问题、证据、严重程度、整改建议、具体尺寸、优先级。
```

3. 厨房专项使用工作三角原则自查。
4. 采光专项使用朝向、窗地比、暗房检查清单自查。
5. 构造规范问题必须提示用户咨询专业结构工程师和当地规范。
